# Project Overview

**App Name:** *(bhai chara)*
**Type:** Private Invite-Only Social Media App
**Platform:** Flutter (Android APK — no Play Store)
**Backend:** Supabase + ImageKit + LiveKit

---

## Purpose

A closed, invite-only social platform built for a trusted circle of friends and family. Unlike public social media apps, this app is not open to the public — only people invited by the admin can join. It combines the best features of Instagram and WhatsApp into one private space: photo sharing, real-time messaging, voice and video calls, group calls, and live streaming — all within a verified, known community.

---

## Problem It Solves

Public social media apps are open, noisy, and filled with strangers. For people who want to stay connected with a specific trusted group — especially when members are spread across different countries like UAE, Saudi Arabia, Qatar, India — there is no simple private platform that combines photo sharing, calling, and live streaming in one place without relying on multiple apps. Additionally, standard VoIP services are restricted in Gulf countries, making calls unreliable for users there.

---

## Solution

A Flutter-based APK distributed privately via WhatsApp. The superadmin creates the first account, generates invite codes, and shares them with trusted contacts. Friends download the APK, sign up using their mobile number or Gmail under that admin's circle, and immediately get access to all features. All real-time communication is routed through a self-hosted LiveKit server using TCP port 443, which bypasses VoIP restrictions in Gulf countries without any extra configuration needed from users.

---

## Core Features

**Authentication & Onboarding**
Mobile OTP and Gmail OAuth via Supabase Auth. New users can only register using a valid invite code generated by the superadmin.

**Photo Feed**
Users can post photos with captions. No video posts. Feed supports likes and comments. Images are stored and served via ImageKit CDN for fast global loading.

**Messaging**
One-to-one direct messages and group chats powered by Supabase Realtime. Messages are instant, no polling.

**Voice and Video Calls**
One-to-one voice and video calls via LiveKit. Works in UAE, Saudi Arabia, Qatar and other Gulf countries through TCP 443 routing.

**Group Calls**
Multiple members can join a single audio or video room simultaneously. No minute limits.

**Live Streaming**
Any member can go live. All other members in the circle get notified and can join as viewers in real time. HD quality.

**Invite System**
Only the superadmin can generate invite codes. Each code is single-use and ties the new user to that admin's circle permanently.

## Target Users

A private group of friends and family, primarily based across India and Gulf countries (UAE, Saudi Arabia, Qatar), who want one single app to share moments, communicate, and stay connected without the noise of public social media.

---

## Key Technical Decisions

- **No Play Store or App Store** — APK is distributed manually, keeping the app fully private
- **Self-hosted LiveKit** — eliminates per-minute call costs entirely, giving unlimited calling and streaming
- **TCP 443 routing via coturn** — makes all calls and live streams work reliably in Gulf countries where standard VoIP is blocked
- **Supabase as primary backend** — handles auth, database, and realtime chat in one platform, reducing complexity
- **ImageKit for media** — 20GB free storage with built-in CDN and automatic image optimization
